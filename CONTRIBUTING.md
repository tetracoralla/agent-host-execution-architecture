# Contributing

Keep contributions focused on the public architecture, terminology, adoption,
claim boundaries, related work, and accurate links to independently owned
repositories.

Run:

```sh
python3 scripts/check_repository.py
```

Do not copy provider/runtime source, add a universal opaque invocation schema,
or turn one implementation detail into a cross-provider standard. New public
claims must identify the current observation or deterministic check that
supports them and what remains unknown.

Contributions are licensed under Apache-2.0 unless clearly stated otherwise.
