# Security policy

Report vulnerabilities through GitHub private vulnerability reporting. Include
the affected revision, a minimal reproduction, impact, and suggested
mitigation. Do not disclose credentials, private data, or exploit details in a
public issue.

This repository contains documentation and a repository checker. Security
issues in Capability, Procedure, Direct Execution Runtime, or a provider should
be reported to that owning repository. This architecture is not an operating-
system sandbox, credential vault, or side-effect authorization mechanism.
